## Deployment to GitHub Pages (Automated)

This repository includes a pre-configured GitHub Actions workflow in `.github/workflows/deploy.yml`.

### 1-Step Setup on GitHub:
1. Push this code to your GitHub repository on branch `main`.
2. On GitHub, go to your repository **Settings** -> **Pages**.
3. Under **Build and deployment** -> **Source**, choose **GitHub Actions**.
4. GitHub will automatically trigger the workflow and publish your site!
5. Your live link will be: `https://<your-username>.github.io/<repo-name>/`

---

## Alternative 1-Click Deployment (Vercel / Netlify)

- **Vercel**: Import your GitHub repository, choose **Vite** preset, and click **Deploy**.
- **Netlify**: Connect your GitHub repository, set build command `npm run build` and publish directory `dist`.
