## Key Highlights & Features

- **Permanent Sleek Dark Mode**: Tailored executive visual design (`#070B14`, `#0B1020`, `#111827`) with neon cyan (`#38D9FF`) and cobalt blue (`#4F8CFF`) ambient lighting.
- **Deep Routing & Instant SPA Support**: Configured with `HashRouter` and custom `404.html` redirection to guarantee 100% route persistence across direct links and page refreshes on GitHub Pages.
- **Vector Brand Logo Ecosystem**: Custom high-fidelity SVG brand marks for Python, React, TypeScript, Shopify, Hostinger, OpenAI, PyTorch, Hugging Face, GUVI, Scaler, Nextwave, and Sololearn.
- **Micro-Interactions & Motion**: Smooth physics-based transitions with Framer Motion, interactive card hover elevations, and responsive glassmorphic cards.
- **Accreditation Portfolio**: 2-column executive certifications layout with verified credentials, skills tags, curriculum inspection modal, and direct online verification links.
- **Direct Contact Channel**: Google Apps Script integration for instant message delivery without mail client redirects.

## Quick Start (Local Development)

```bash
# Clone repository
git clone https://github.com/yagnasrireddymukku/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

## Deployment to GitHub Pages (Automated)

This repository includes a pre-configured GitHub Actions workflow in `.github/workflows/deploy.yml`.

### 1-Step Setup on GitHub:
1. Push this code to your GitHub repository:
   ```bash
   git remote add origin https://github.com/yagnasrireddymukku/portfolio.git
   git push -u origin main
   ```
2. On GitHub, go to your repository **Settings** -> **Pages**.
3. Under **Build and deployment** -> **Source**, choose **GitHub Actions**.
4. GitHub will automatically trigger the workflow and publish your site!
5. Your live link will be: **`https://yagnasrireddymukku.github.io/portfolio/`**
